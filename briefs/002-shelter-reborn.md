# 브리프 002 — Shelter Reborn

- 종류: 기능
- 모드: 해당 없음
- 작가: 해당 없음
- 작성일: 2026-10-15

## 목표
동물 보호·재활 구역을 복원하고 확장해 나가는 캐주얼 게임을 기획한다. 플레이어는 작은 임시 보호 구역에서 시작해, 미니게임을 클리어하며 안전한 공간, 치료 구역, 이동 통로, 식량/물 공급 시설을 만들고, 점점 더 큰 생태 보호 지역을 만든다. 게임의 핵심 경험은 단순한 정원 꾸미기가 아니라, ‘동물이 살아갈 수 있는 환경을 복원하는 것’이다.

## 필수 요소
- 배경은 정원/농장/동물 관리형이 아니라 “동물 보호 재활 구역” 또는 “복원된 보호 섬/기지”로 설정한다.
- 플레이어는 작은 입구 구역에서 시작해, 미니게임을 완료하며 새로운 구역을 해금한다.
- 각 구역은 서로 다른 테마를 가진다: 임시 보호 터, 비상 재활 구역, 이동 통로, 숲 보호 구역, 강가 복원 지대 등.
- 각 구역을 열기 위해 테트리스, 퍼즐, 블록 매칭, 같은 색 블록 쌓기, 아케이드형 미니게임 등이 사용된다.
- 구역 안에는 동물, 자원, 의료 시설, 물과 식량 공급, 안전 통로, 쉼터 등이 등장한다.
- ‘무한 확장’ 구조를 유지하되, 각 구역은 직관적으로 구분되고 점진적인 난이도 상승을 가진다.
- 플레이의 의미는 “동물을 키우는 게임”이 아니라 “살아갈 수 있는 환경을 되살리는 게임”이다.
- 미니게임을 완료하면 보호 구역이 실제로 살아나는 시각적 피드백이 있어야 한다.
- 게임 내부에서 구조 활동과 복원 활동이 연결되어야 한다.
- 사용자에게 친근하고 희망적인 감정을 주되, 보호/재활의 무게감은 유지한다.
- 수익 구조는 광고 수익과 유료 결제를 별도로 분리하고, 기부형 결제는 별도 섹션으로 둔다.
- 기부 구조는 운영 비용을 제외한 90%가 실제 보호/구조 활동에 사용되는 형태로 설계한다.
- 운영자의 10% 수익은 비용 구조로 명시되며, 기부의 신뢰성을 해치는 방식은 피한다.
- 저작권 충돌을 피하기 위해 “정원 꾸미기”라는 기존 장르 감성보다 “복원 구역/보호 기지”를 중심으로 고유한 세계관을 만든다.

## 제약
- 정원/농장/동물 관리 게임의 이미지를 너무 직접적으로 차용하지 않는다.
- 유명한 기존 게임의 IP, 캐릭터, 심볼, 사운드, UI 감각을 흉내 내지 않는다.
- 게임은 단순한 “꾸미기”가 아니라 “복원과 보호”를 중심으로 설계한다.
- 기부금/영수증의 표현은 고지사항과 회계 구조를 명확히 분리해야 한다.
- 광고 수익은 운영 자금으로 사용되며, 기부 수익과 혼동되지 않아야 한다.
- 메인 루프는 짧고 반복 가능한 미니게임 중심이며, 큰 장기적 목표는 보호 구역의 확장이다.
- 구역은 이질적으로 보이지 않게, 전체 생태계와 연결된 흐름을 유지한다.
- 무한 확장 속에서도 각 구역의 목표와 난이도는 명확히 구분해야 한다.

## 완료 조건
- [ ] 플레이어는 이 게임이 “동물을 키우는 게임”이 아니라 “보호 구역을 복원하는 게임”이라는 점을 이해한다.
- [ ] 입구 보호 구역에서 시작해, 미니게임을 통해 구역이 점점 열리고 확장되는 구조를 확인할 수 있다.
- [ ] 각 구역마다 서로 다른 테마와 목표가 존재한다.
- [ ] 미니게임 완료 후, 새로운 공간/시설/동물/자원이 등장하는 피드백이 있다.
- [ ] 플레이어는 점점 더 깊은 구역으로 들어갈수록 난이도가 올라간다는 것을 느낀다.
- [ ] 게임의 메시지와 기부 구조가 연결되어 있다.
- [ ] 정원 게임이라기보다 “복원 구역”이라는 고유한 배경이 전달된다.
- [ ] 수익 구조에서 운영 자금과 기부금이 분리되어 있으며, 90% 기부 구조가 명확히 드러난다.

## 하지 않을 것
- 정원/농장/동물 관리 게임의 뼈대와 문법을 그대로 복사하지 않는다.
- 광고 수익과 기부금을 같은 항목으로 표현하지 않는다.
- 정원 꾸미기만으로 게임을 설명하지 않는다.
- 단순한 감성 메시지로만 게임을 설계하지 않는다.
- 각 구역이 서로 무관하지 않은 상태로 만들지 않는다.
- 보호와 복원이 공간의 확장과 연결되지 않는 구조로 만들지 않는다.

## 핵심 설계 메모
- 배경은 정원 대신 재생 보호 구역, 복원 기지, 보호섬, 재활 캠프 등으로 설정한다.
- 플레이어는 동물들을 “기르기”보다 “살 수 있는 환경을 만드는 것으로 이해한다.
- 미니게임은 항상 보호 구역을 만드는 행위와 연결되어야 한다.
- 무한한 확장과 구역별 구조를 동시에 유지한다.
- 결과적으로 게임은 “소셜 임팩트 + 캐주얼 플레이 + 구조/복원 메시지”를 동시에 담는 형태가 된다.

## 기본 아이디어 요약
이 게임은 동물을 구하는 액션 게임이 아니라, 동물들이 살아갈 수 있는 공간을 복원하고 확장하는 생태 보호 게임이다. 구역을 열어야 하고, 미니게임을 클리어해야 하며, 점점 더 깊은 곳으로 들어가면서 위험한 환경을 안전하게 바꿔나간다. 플레이어는 자신이 만든 공간에서 동물들이 살아가는 모습을 보고, 게임을 통해 실제 보호 활동에 기여하는 구조를 체감하게 된다.
