# 미니게임 세부 규칙 가안

## 1. 공통 원칙
미니게임은 단순히 점수를 얻는 활동이 아니라, 보호 구역을 복원하는 행동과 연결되어야 한다.

모든 미니게임은 아래 공통 규칙을 따른다.

- 플레이어는 제한된 시간 안에 목표를 달성해야 한다.
- 성공 시 보호 구역의 특정 기능이 활성화된다.
- 실패해도 진행은 유지되지만, 자원이나 보상이 줄어든다.
- 각 미니게임은 같은 보상 구조를 가진다.
  - 안전 경로 확보
  - 보호 시설 완성
  - 자원 증대
  - 물/식량/치료 공급
  - 다음 구역 해금
- 각 스테이지는 기본 미니게임 2개 + 보너스 미니게임 1개를 가진다.

## 2. 보상 체계
미니게임 성공 보상은 딱 세 가지로 나눌 수 있다.

1. 구조 자원 보상
   - 물, 식량, 치료재, 방어 자재
2. 환경 보상
   - 안전 통로, 쉼터, 울타리, 물길
3. 지역 보상
   - 다음 구역 해금, 보호 구역 확장, 동물 입주 가능

실패 시에는 다음이 발생한다.
- 자원 감소
- 보호 구역 완성도 감소
- 동물 이동 가능 시간 지연
- 다음 작업의 난이도 증가

## 3. 미니게임 1: 경로 정리 퍼즐
### 목적
동물이 안전하게 이동할 수 있는 통로를 만든다.

### 플레이 방식
- 격자형 보드 상에서 빈 칸과 장애물을 배치한다.
- 플레이어는 경로를 연결해 동물 이동 통로를 완성한다.
- 일부 칸은 물, 안전 소나무, 벽, 장애물이 존재한다.

### 규칙
- 경로는 시작점에서 도착점까지 연결되어야 한다.
- 통로는 최소 길이 조건을 만족해야 한다.
- 장애물은 피하거나 우회해야 한다.
- 같은 구역을 너무 비효율적으로 만들면 점수가 낮아진다.

### 성공 조건
- 시작점에서 목적지까지 안전한 경로가 완성된다.
- 통로의 지름길이 기준을 통과한다.
- 장애물이나 위험 구간을 피한 경로를 만들었다.

### 실패 조건
- 경로가 끊기거나, 안전한 통로가 완성되지 않았다.
- 동물 이동이 불가능한 상태가 된다.

### 보상
- 보호 경로 확보
- 이동 가능한 동물 수 증가
- 다음 스테이지의 동물 입주 활성화

### 난이도 조절
- 초반: 3~5칸 길이
- 중기: 6~8칸 길이, 장애물 증가
- 후기: 경로가 2개 이상 존재하고, 위험 구간이 추가됨

## 4. 미니게임 2: 자원 블록 매칭
### 목적
물, 식량, 치료재 등 필요한 자원을 조합해 보호 구역을 유지한다.

### 플레이 방식
- 여러 색상/종류의 블록이 떨어지거나 배열된다.
- 같은 종류의 블록을 연결하거나 정렬해 조합을 완성한다.
- 일부 블록은 보너스 자원으로 작동한다.

### 규칙
- 같은 자원 종류 3개 이상 연결 시 생성된다.
- 특정 조합은 더 높은 보상값을 준다.
- 카드형 또는 격자형이 모두 가능하다.
- 연쇄 반응이 발생하면 추가 보상을 획득한다.

### 성공 조건
- 목표 자원량을 채우면 성공한다.
- 특정 조합이 완성되면 추가 보너스가 발생한다.

### 실패 조건
- 목표 자원량을 달성하지 못한다.
- 자원 유출이 많아서 보호 시설을 유지하지 못한다.

### 보상
- 물, 식량, 치료재 확보
- 보호 쉼터 유지 가능
- 보호 구역 안정도 증가

### 난이도 조절
- 초반: 3종류 자원만 필요
- 중반: 자원 유형 4~5개
- 후기: 여러 자원 조합을 동시에 처리

## 5. 미니게임 3: 기본 아케이드 회피형
### 목적
위험 구역을 피하면서 안전한 통로를 확보한다.

### 플레이 방식
- 플레이어 캐릭터를 좌우/상하로 이동시킨다.
- 장애물과 위협 요소를 피하면서 목적지까지 이동한다.
- 일부 동물은 통로를 따라 자동으로 이동한다.

### 규칙
- 충돌 시 일정 체력 감소
- 일정 횟수 이상 충돌하면 실패
- 보호 구역의 안정도가 함께 상승하거나 하락한다.
- 별도 보너스 아이템을 획득하면 더 많은 자원이 제공된다.

### 성공 조건
- 목적지 도착
- 충돌 회수를 기준 내로 유지
- 남은 체력 기준을 충족해야 한다.

### 실패 조건
- 체력 소진
- 시간 초과
- 동물 보호 경로가 파괴됨

### 보상
- 안전 통로 확보
- 방어 장치 설치
- 보호 경계 완성

### 난이도 조절
- 초반: 적이 느리고 경로가 단순함
- 중반: 속도 증가, 장애물 추가
- 후기: 복합 패턴의 이동 필요

## 6. 미니게임 4: 같은 색 블록 쌓기
### 목적
보호 구조물이나 울타리를 안정적으로 세운다.

### 플레이 방식
- 같은 색 블록을 쌓아 구조물을 형성한다.
- 높이와 균형을 유지해야 한다.
- 특정 부분을 비워서 통로를 남겨야 한다.

### 규칙
- 같은 색 블록이 연속으로 쌓여야 안정적이다.
- 잘못된 순서로 쌓으면 구조물이 붕괴될 수 있다.
- 가장 낮은 층이 약하면 전체 구조물 붕괴 가능

### 성공 조건
- 구조물의 안정성을 확보하면 성공
- 필요한 높이와 완성도가 달성되면 보상

### 실패 조건
- 구조물이 무너짐
- 목표 높이에 도달하지 못함

### 보상
- 울타리, 쉼터, 보호 장벽 확보
- 동물 서식 공간 안정화

### 난이도 조절
- 초반: 2~3단계 구조물
- 중반: 높이와 무게를 함께 고려
- 후기: 구조물 붕괴를 방지해야 함

## 7. 미니게임 5: 색상 조합형 환경 설계
### 목적
지형과 보호 환경을 맞게 구성한다.

### 플레이 방식
- 특정 기능을 가진 자원(물, 식량, 치료, 안전)이 같은 색상 조합으로 배치된다.
- 플레이어는 올바른 조합으로 환경 특성을 구현한다.

### 규칙
- 같은 색상 또는 같은 유형의 조합은 보너스 발동
- 특정 조합이 없으면 보호 기능이 약해짐
- 일부 조합은 동물 종류에 따라 효과가 다르다

### 성공 조건
- 환경 안정도 점수가 기준 이상이 되면 성공
- 동물 서식 조건을 충족하면 보상

### 실패 조건
- 환경 안정도가 낮아 보호 기능이 약해짐
- 특정 서식 조건을 충족하지 못함

### 보상
- 보호 환경 확장
- 동물 입주 가능
- 다음 구역 해금

## 8. 스테이지 1에서의 적용 규칙
스테이지 1은 아래 3개 미니게임만 사용한다.

1. 경로 정리 퍼즐
2. 자원 블록 매칭
3. 기본 아케이드 회피형

이렇게 나누는 이유는 플레이어가 전체 시스템을 너무 빨리 이해하지 못하게 만들지 않기 위해서다.

## 9. 난이도 설계 원칙
- 첫 미니게임은 익숙하고 직관적이어야 한다.
- 두 번째 미니게임은 자원과 공간을 함께 다뤄야 한다.
- 세 번째 미니게임은 약간의 속도감과 긴장감을 준다.

즉, 스테이지 1에서는
- 개념 이해
- 기본 조작 학습
- 보호 활동의 의미 이해
이 세 가지를 동시에 학습해야 한다.

## 10. 최종 규칙 요약
미니게임은 다음 순서로 설계한다.

1. 보호 구역의 필요한 요소를 정한다.
2. 그 요소를 만들어내는 게임 방식을 고른다.
3. 성공 시 보호 기능을 활성화한다.
4. 실패 시 자원 손실이나 안정도 감소를 준다.
5. 모든 미니게임은 구역 복원과 연결되어야 한다.

## 11. 한 줄 결론
미니게임은 단순한 재미를 위한 도구가 아니라, 플레이어가 “보호 구역을 복원한다”는 사실을 체감하게 만드는 핵심 장치다.
